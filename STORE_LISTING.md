# Chrome Web Store listing copy for Jump

## Name (max 75 characters)
Jump: Fuzzy Tab Switcher

## Summary (max 132 characters)
Find and switch to any open or recently closed tab by typing a few letters of its title or address.

## Category
Workflow & Planning (alternative: Tools)

## Description
Too many tabs? Press Ctrl+Shift+Space (Cmd+Shift+Space on Mac), type a few letters, press Enter.

Jump searches every open tab across all your windows, plus your recently closed tabs, by title and by address. You don't need to type exactly: "gthb" finds GitHub, "mdn grid" finds the MDN page on CSS grid, and "3000" finds your localhost dev server.

• Search all windows at once
• Reopen recently closed tabs from the same box
• Press Enter on an empty search to jump back to your previous tab
• Close tabs from the list with Ctrl+Delete (Cmd+Backspace on Mac)
• Works fully offline. No accounts, no tracking, no data leaves your browser

Change the shortcut anytime at chrome://extensions/shortcuts.

## Single purpose (Privacy tab)
Jump lets users search their open and recently closed tabs and switch to the one they pick.

## Permission justifications (Privacy tab)
tabs: Needed to read the title and address of open tabs so they can be searched, and to switch to or close the tab the user selects.
sessions: Needed to list recently closed tabs so the user can search and reopen them.
favicon: Needed to show each tab's icon from Chrome's local favicon cache, so the extension never requests images from websites.
